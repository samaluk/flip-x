# Verified learning inbox

This is temporary staging for durable, non-obvious discoveries verified while working in Flip-x. Promote each accepted lesson with [the shared `lessons-to-config` skill](.agents/skills/lessons-to-config/SKILL.md), then remove it from this file.

Capture only facts that remain useful after the current task. Each lesson should state the observation, the verified invariant, the evidence, and its proposed durable destination.

Do not record game or scoring bugs, feature ideas, task notes, speculative architecture, transient test output, workarounds whose cause is gone, or secrets. Unresolved development-process friction belongs in [Frog](.agents/friction-log/README.md).
